# NULL (Fabric, Minecraft 26.2)

Based on the Unstable Universe lore: NULL, the army of scrambled-name hunters led by whoever holds the Totem of NULL.

## Use
1. `/null totem` (op) gives the Totem of NULL. **Carry it anywhere in your inventory and you own NULL**
   (you join the NULL team, get a title, leader buffs, and the army stops attacking you). Drop it and you lose it.
2. `/null orders` lists categories, `/null orders squads` etc. lists orders, `/null order <id>` runs one.
   Destructive orders (marked [!]) need `/null order <id> confirm`.
3. Schematics: put `.schem`, `.litematic` or `.nbt` files in `config/null_mod/schematics/`, then stand where the
   build's min corner should be and run `/null build <name> [blocksPerTick]`. The `build_*` orders look for files
   named `null_overworld_capital`, `null_nether_capital`, `null_end_capital`, `null_end_stronghold_base`, `null_outpost`,
   `null_end_prison`, `null_orbital_cannon`, `null_portal_strike_platform`, `null_barracks`, `null_wall`,
   `null_watchtower`, `null_vault`.

## Edit orders
Orders are generated by `gen/gen_orders.py` into `src/main/resources/null_mod/orders.json` (vanilla commands, `@s` = you).

## Build
Needs JDK 25 and Gradle 9.x: `gradle wrapper --gradle-version 9.4` once, then `./gradlew build`; jar is in `build/libs/`.

## Known limits
- Written without being able to compile against 26.2 here: if Gradle reports a renamed method, send me the error.
- Schematics place blocks only (no chest contents / block entity data) and keep their saved rotation.
- Soldiers are vanilla mobs with scrambled names, netherite gear and the `null_army` tag (no custom skins).

## End Empire
`/null orders empire` has the End Empire orders: `empire_declare`, garrisons of the main island and exit portal,
endermen/shulkers joining NULL, curses on visitors in the End, and `empire_build_*` (stand in the End first).
`/null order empire_passive_on` makes the End obey you while you carry the Totem there: endermen and shulkers join
NULL and a 6-elite patrol re-spawns near you every 10 seconds when none is nearby.

## White castle and NULL capital
- `/null castle white` (or order `empire_build_white_castle`): big white End castle, 61x61 footprint, plinth, curtain wall,
  4 corner towers, keep with 2 floors + ladder, 4 turrets and a ~85-block spire. Min corner = your feet, gate faces south (+z).
  On the End main island stand ~100 blocks from the exit portal first (e.g. at x=-30, z=80 looking at flat ground).
- `/null stronghold` runs /locate for the nearest stronghold (do it in the Overworld, travel there, stand on the surface above it).
- `/null castle capital` (or `capital_build_null_capital`): the same castle in blackstone/purple as the NULL capital.
  `/null orders capital` has the garrison and claim orders.

## Build without installing anything (GitHub)
1. Make a free GitHub repo and upload the contents of this folder (keep the `.github` folder).
2. Open the repo's Actions tab, wait for the `build` run to finish (or run it with "Run workflow").
3. Open the finished run, download the `null-mod` artifact, unzip it: `null-mod-1.0.0.jar` is the mod.
   (Ignore any `-sources` jar.) Put it plus Fabric API in your instance's `mods` folder.
